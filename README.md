# Vital City Index (VCI) Calculator

## Overview

Urban design has conventionally been evaluated using criteria other than those directly 
address human neurological and cardiovascular health. The Vital City Index (VCI) 
conceptualizes cities as exposure systems acting on the brain–heart axis to fill the lack of 
spatially explicit frameworks which systematically link urban morphology to 
neurophysiological pathways and biological domains. The VCI conceptualizes six urban 
vital signs, each defined by equations which map quantifiable spatial characteristics to 
these pathways. Shared inputs are allocated across pathways using fractions derived from 
meta-analytic effect sizes, and non-linear dose–response transformations and interaction 
terms encode the brain–heart axis. The Urban Physiological Resilience Index (UPRI), 
expressed as a protective-resource-to-stressor ratio, classifies neighborhoods into four 
typologies. Application of the framework to 19 sites, identifies circadian disruption due to 
nighttime heat as the primary driver of intercity variation. These results show a climate specific vulnerability that is not captured by conventional daytime-focused assessment 
protocols.

## Prerequisites

- **Python**: 3.8 or higher
- **Operating System**: Windows, macOS, or Linux
- **Dependencies**: Only Python standard library modules are required (no external packages)

## Installation

### 1. Clone or Download the Repository
```bash
git clone <repository-url>
cd VCI
```

### 2. Create a Virtual Environment (Recommended)

#### On Windows:
```bash
python -m venv .venv
.venv\Scripts\activate
```

#### On macOS/Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

While the project uses only standard library modules, you can optionally verify the Python version:
```bash
python --version
```

## Usage

### Running the VCI Calculator

Once your environment is set up and activated, run the application:

```bash
python run.py
```

This will launch the VCI Calculator GUI window. The application provides a graphical interface where you can:

1. Enter urban environmental parameters (PM2.5, temperature, NDVI, GVI, green space access, etc)
2. Calculate the Vital City Index based on these inputs
3. View the Urban Physiological Resilience Index (UPRI) results
4. Classify neighborhoods into resilience typologies

│   ├── GenerateUI.py                  # GUI components and user interface generation

### Module Descriptions

- **Core.py**: Contains the `VciCalculator` class that orchestrates the entire application, managing UI interactions and coordinating calculations between different modules.

- **GenerateUI.py**: Handles all GUI components and layout, providing input fields for environmental parameters and displaying calculation results.

- **UrbanVitalSigns.py**: Implements equations and calculations for the six urban vital signs that map spatial characteristics to neurophysiological pathways.

- **IntegrationResilience.py**: Calculates the Urban Physiological Resilience Index (UPRI) and classifies neighborhoods into resilience typologies.

- **SpecificationRules.py**: Enforces specification rules, validates inputs, and ensures calculations meet defined requirements.
